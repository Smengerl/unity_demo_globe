Notes:
- NASA's media usage guidelines say NASA content is generally not subject to copyright and may be used with credit, without implying NASA endorsement and without NASA logos. Individual images can carry exceptions; the sources used here are NASA Earth Observatory products and carry none on their pages.
- The terrain tiles combine many sources (SRTM is public domain; some national datasets, e.g. European, Swiss, Austrian, UK, are open data with attribution requirements). Which source covers a given tile is documented in the link above. This review did **not** check source by source; the safe course is to keep the attribution line above in the app's credits page. The derived textures in this repository are heavily transformed (slope maps, masks, distance fields), which lowers but does not remove the attribution duty.

## 4. Code dependencies and tools

- **Unity packages** (`Packages/manifest.json`): the packages used (`com.unity.render-pipelines.universal`, `com.unity.inputsystem`, `com.unity.ugui`, `com.unity.test-framework`, IDE integrations) are under the Unity Companion License, which allows use, modification and redistribution **only together with Unity**. It is not an OSI open-source licence. Consequence: this repository can only be used inside Unity projects, which is its purpose anyway. The repository contains none of their source code.
- **Unity Editor**: free for individuals and small companies under Unity's revenue thresholds, otherwise a paid plan. The runtime fee that Unity announced in 2023 was cancelled in 2024; verify the current terms before shipping.
- **Shaders, C#**: all written for this project. The techniques (quintic ramps, hash-based noise, cell grids, Meeus astronomy formulas, Terrarium decoding) are standard published methods; no third-party shader code was copied.
- **HUD icons**: line icons drawn from short SVG path strings written for this project (`Assets/Hud/HudIcons.cs`), not copied from an icon set. As with any simple pictogram (globe, plane, chart) similarity to other sets is possible; they are generic shapes.
- **Python tools**: `numpy` (BSD-3-Clause) and `Pillow` (HPND) are used at build time only.

## 5. Proposed licence for this repository

**Recommendation: MIT** for all own code and own assets, with the third-party material above staying under its own terms.

Why MIT:
- Short, permissive, widely understood in game development; the code can go into the real (closed-source) game without obligations beyond keeping the copyright notice.
- Compatible with everything used here (OFL fonts, UCL packages, public-domain-style NASA data).
- No copyleft burden for users of the globe view.

Alternatives:

| Option | Choose it if | Trade-off |
|---|---|---|
| **MIT** (recommended) | you want maximum reuse and no friction | no patent grant; no protection against closed forks |
| Apache-2.0 | you want an explicit patent grant | longer; requires NOTICE handling |
| MPL-2.0 | you want improvements to the view's files to flow back, but allow use in closed games | file-level copyleft; some friction |
| All rights reserved (no licence) | the repository stays private and the code may become part of a commercial product | others may not legally use it, even if it goes public by accident |

If the repository stays private, no licence is required, but adding one now is harmless and makes a later publication clean. Whatever is chosen, the textures keep their credit lines (section 2) and the fonts their OFL notices.

Suggested file header for the licence: `Copyright (c) 2026 Simon Gerlach` (adjust to the legal owner). Place a `LICENSE` file in the repository root and replace the last line of the README's credits section.
